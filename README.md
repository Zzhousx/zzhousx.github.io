# Shixuan Zhou — Academic Homepage

Personal academic homepage of Shixuan Zhou, School of Software Engineering,
South China University of Technology.

Website: https://zzhousx.github.io/

## Update the site

Edit `profile.js` for the biography, news, publications, patents and awards.
Chinese translations use fields ending in `Zh`; interface labels are in `i18n.js`.
The website starts in English on every visit and offers a Chinese language switch.

This is a static HTML/CSS/JavaScript site. GitHub Pages publishes the root of the
`main` branch. No installation or build step is required.

To preview locally, run `python -m http.server 8000` in this directory.
